# Yasina Love Experience

یک وب‌سایت عاشقانه‌ی سه‌مرحله‌ای با React + TypeScript + Vite. بدون سرویس خارجی، بدون کلید API و بدون بک‌اند.

## ۱. اجرا روی کامپیوتر خودت

نیاز داری: **Node.js نسخه ۱۸ یا بالاتر** (نسخه‌ی LTS از nodejs.org). بعد از نصب، در ترمینال بزن:

```bash
node -v          # باید ۱۸ یا بالاتر نشان بدهد
cd yasina-love-experience
npm install      # نصب وابستگی‌ها (فقط بار اول لازم است، به اینترنت نیاز دارد)
npm run dev      # اجرای محلی؛ آدرس http://localhost:5173 را در مرورگر باز کن
npm run build    # ساخت نسخه‌ی نهایی در پوشه dist/
npm run preview  # پیش‌نمایش نسخه‌ی build شده، آدرس http://localhost:4173
```

`npm run build` باید بدون خطا تمام شود و پوشه‌ی `dist/` بسازد. اگر خطا دیدی، خروجی ترمینال را نگه دار.

## ۲. فایل‌هایی که باید شخصی‌سازی کنی

| چه چیزی | کجا |
|---|---|
| متن‌ها، جواب‌ها، متن فال، پیام پایانی | `src/data/love-content.ts` |
| عکس | `public/images/our-photo.jpg` |
| فایل صوتی | `public/audio/our-voice.mp3` |
| رنگ‌ها | `src/styles.css` (بخش `:root` بالای فایل) |
| اندازه‌ی قلب‌ها | `src/styles.css` (کلاس `.hanger`) |
| طول نخ‌ها و سرعت تاب خوردن | `src/components/Stage1Hearts.tsx` |

اگر عکس یا فایل صوتی نباشد، سایت به‌جای شکستن، یک پیام راهنما نشان می‌دهد.

## ۳. عکس خودت را جایگزین کن

1. عکس خودت را در کامپیوتر آماده کن. بهتر است عمودی یا افقی باشد با حجم کمتر از ۱ مگابایت (برای موبایل سریع‌تر لود می‌شود).
2. فایل را با نام دقیق **`our-photo.jpg`** داخل پوشه `public/images/` بگذار و جای فایل قبلی را بگیر.
3. اگر عکس PNG است، با ابزار زیر به JPG تبدیل کن، یا مستقیم `.png` بگذار و در `src/data/love-content.ts` مسیر `photo.src` را به `/images/our-photo.png` تغییر بده.

برای تبدیل با ffmpeg (اختیاری):

```bash
ffmpeg -i my-photo.png -q:v 3 public/images/our-photo.jpg
```

عکس روی صفحه با حفظ نسبت تصویر نمایش داده می‌شود. با کلیک روی آن نسخه‌ی بزرگ باز می‌شود و دکمه‌ی دانلود فایل `yasina-our-photo.jpg` را ذخیره می‌کند.

## ۴. فایل ویس ده‌دقیقه‌ای را اضافه کن

1. فایل صوتی را با نام **`our-voice.mp3`** داخل `public/audio/` بگذار.
2. اگر فایل شما `.m4a`، `.wav` یا `.ogg` است، می‌توانی با ffmpeg به MP3 تبدیل کنی. برای فایل‌های طولانی مثل ویس ۱۹ دقیقه‌ای، تبدیل به **mono با ۶۴ kbps** حجم را از حدود ۱۹ مگابایت به حدود ۹ مگابایت می‌رساند و روی موبایل سریع‌تر پخش می‌شود:

```bash
ffmpeg -i my-voice.m4a -vn -ac 1 -b:a 64k public/audio/our-voice.mp3
```

3. اگر خواستی فرمت یا نام دیگری استفاده کنی، در `src/data/love-content.ts` مقدار `stageThree.audio.src` را تغییر بده.

پخش خودکار نداریم: کاربر باید خودش روی «▶» بزند. اگر فایل پیدا نشود، پیام راهنما نشان داده می‌شود.

## ۵. متن فال را تغییر بده

متن‌های فال واقعی هنوز داده نشده‌اند و در فایل فعلی جای‌گذار هستند. فایل `src/data/love-content.ts` را باز کن و بخش `fortune.pool` را پیدا کن:

```ts
pool: [
  'متن فال اول رو اینجا بنویس 🌹',
  'متن فال دوم رو اینجا بنویس 🌷',
  'متن فال سوم رو اینجا بنویس 💕',
],
```

هر متن را داخل یک جفت ' ' بنویس و بین آن‌ها ویرگول بگذار. هرچقدر متن بیشتری اضافه کنی، دکمه‌ی «فال دیگه» بیشتر تنوع دارد. عنوان کارت را هم می‌توانی در `fortune.title` عوض کنی.

## ۶. پیام پایانی را تغییر بده

در همان فایل `src/data/love-content.ts` مقدار `stageThree.finalMessage` را عوض کن:

```ts
finalMessage: 'با تمام وجودم دوستت دارم. ماهگردمون رو بهت تبریک می‌گم، عزیزم. ❤️',
```

این پیام زیر کارت فال، با حالت تایپ شدن نمایش داده می‌شود. کاربر می‌تواند با دکمه‌ی «نمایش کامل» تایپ را یک‌جا ببیند.

## ۷. رنگ‌ها و اندازه‌ی قلب‌ها

**رنگ‌ها**: بالای `src/styles.css` بخش `:root` هست:

```css
:root {
  --pastel-pink: #ffd6e3;   /* صورتی پاستلی */
  --hot-pink: #e63977;      /* صورتی پررنگ (دکمه‌ها و تیترها) */
  --blush: #f6c9bc;         /* گلبهی */
  --soft-red: #e0606e;      /* قرمز ملایم */
  --warm-white: #fff8f4;    /* سفید گرم */
  --sky: #8fcfef;           /* آبی آسمانی */
}
```

کد رنگ را عوض کن و ذخیره کن؛ همه‌ی بخش‌ها هم‌رنگ می‌شوند. رنگ هر قلب در `Stage1Hearts.tsx` در آرایه‌ی `HEART_COLORS` است.

**اندازه‌ی قلب‌ها**: در `src/styles.css` کلاس `.hanger` این خط را دارد:

```css
width: clamp(44px, 13vw, 84px);
```

عدد آخر (`84px`) حداکثر اندازه روی دسکتاپ است. مثلاً برای قلب‌های بزرگ‌تر `clamp(52px, 15vw, 110px)` بگذار.

**طول نخ‌ها**: در `src/components/Stage1Hearts.tsx` آرایه‌ی `STRING_LENGTHS` (بر حسب پیکسل) ارتفاع هر قلب را مشخص می‌کند.

## ۸. سایت را منتشر کن (لینک عمومی)

سایت یک صفحه‌ی استاتیک است، پس می‌توانی آن را روی یکی از این سرویس‌ها منتشر کنی. ساده‌ترین روش‌ها:

### روش الف: Netlify Drop (بدون Git، ساده‌ترین)

1. اول `npm run build` را اجرا کن تا پوشه‌ی `dist/` ساخته شود.
2. به `app.netlify.com/drop` برو، حساب رایگان بساز یا وارد شو.
3. پوشه‌ی **`dist`** را روی صفحه بکش. چند ثانیه بعد لینک عمومی مثل `https://xxxx.netlify.app` می‌گیری.

### روش ب: Vercel یا Netlify با مخزن Git (برای به‌روزرسانی آسان)

1. کد را در GitHub یا GitLab بگذار (بخش «نسخه‌ی جدید» را ببین).
2. در Vercel یا Netlify، گزینه‌ی «Import project» یا «Add new site» را بزن و مخزن را انتخاب کن.
3. تنظیمات build به‌صورت خودکار از فایل‌های `vercel.json` یا `netlify.toml` خوانده می‌شوند:
   - Build command: `npm run build`
   - Output directory: `dist`
4. روی Deploy بزن. از این به بعد هر بار که کد را push کنی، سایت خودکار به‌روز می‌شود.

> لینک عمومی فقط بعد از اولین انتشار موفق ساخته می‌شود. تا آن موقع فقط روی کامپیوتر خودت اجرا می‌شود.

## ۹. نسخه‌ی جدید را منتشر کن

**اگر با Git و Vercel/Netlify کار می‌کنی:**

```bash
# بعد از تغییر متن یا عکس یا فایل صوتی:
npm run build        # مطمئن شو build بدون خطا است
git add .
git commit -m "توضیح کوتاه تغییر"
git push             # سایت خودکار به‌روز می‌شود
```

**اگر با Netlify Drop کار می‌کنی:** دوباره `npm run build` را بزن و پوشه‌ی `dist` جدید را روی همان سایت در Netlify بکش (یا در داشبورد سایت، گزینه‌ی Deploy جدید را بزن).

## تبدیل به برنامه (نصب روی گوشی و کامپیوتر)

سایت یک «برنامه‌ی وب» (PWA) است: می‌شود آن را مثل یک برنامه روی صفحه‌ی اصلی گوشی یا ویندوز نصب کرد، با آیکون خودش و تمام‌صفحه اجرا می‌شود و بعد از بار اول آفلاین هم کار می‌کند.

**نکته:** نصب فقط روی آدرس **https** (یا روی localhost) انجام می‌شود. آدرس‌های Cloudflare و Netlify و Vercel https هستند. نسخه‌ی نصبی را از `npm run build` و `npm run preview` (یا از سرویس میزبانی) بگیر، نه از `npm run dev`.

- **اندروید (Chrome):** آدرس سایت را باز کن، منوی سه‌نقطه را بزن، گزینه‌ی «Install app» یا «Add to Home screen» را انتخاب کن.
- **آیفون (Safari):** آدرس را باز کن، دکمه‌ی Share را بزن، «Add to Home Screen» را انتخاب کن. (در iOS باید حتماً با Safari باز شود.)
- **ویندوز (Edge یا Chrome):** آدرس را باز کن، آیکون نصب (+ یا کامپیوتر با فلش) در نوار آدرس را بزن و «Install» را انتخاب کن.

**به‌روزرسانی:** وقتی متن یا عکس را عوض می‌کنی و دوباره `npm run build` و منتشر می‌کنی، کاربران با اتصال اینترنت نسخه‌ی جدید را همان بار بعدی می‌بینند (فایل `public/sw.js` به‌طور خودکار نسخه‌ی تازه را می‌گیرد).

**محدودیت:** برنامه‌ی نصبی برای اندروید و آیفون فایل `.apk` یا `.ipa` نیست؛ یک نسخه‌ی وب نصب‌شده است. اگر لازم باشد در Google Play یا App Store منتشر شود، باید با ابزار جداگانه (مثل Capacitor) ساخته شود که حساب توسعه‌دهنده لازم دارد.

## نکات فنی

- **پاسخ مرحله‌ی دوم فقط در حافظه‌ی برنامه است.** با بستن یا رفرش صفحه پاک می‌شود. هیچ‌جا ارسال یا ذخیره نمی‌شود (نه sessionStorage، نه سرور). اگر بعداً خواستی صاحب سایت پاسخ را ببیند، باید یک بک‌اند یا سرویس فرم اضافه شود.
- **پخش صوت** فقط بعد از کلیک کاربر شروع می‌شود. همه‌ی بخش‌های صوتی از یک المان مشترک استفاده می‌کنند، پس پخش هم‌زمان ندارد.
- **انتقال بین مراحل** قفل کوتاهی دارد (حدود ۰٫۷ ثانیه) تا کلیک‌های سریع نتوانند چند مرحله را رد کنند.
- **فونت** Vazirmatn از طریق `@fontsource` داخل پروژه است و بدون اینترنت هم نمایش داده می‌شود.
- **کاهش انیمیشن**: اگر در سیستم «کاهش حرکت» فعال باشد، انیمیشن‌های تزئینی و تایپ پیام پایانی خاموش می‌شوند.
